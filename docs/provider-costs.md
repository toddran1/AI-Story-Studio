# Provider cost tracking

AI Story Studio records paid provider operations in Postgres and mirrors each accepted record to `stories/<story>/analytics/usage/` so project backups retain a portable audit trail. Records use provider request IDs for idempotency when available and retain the pricing snapshot used at calculation time.

The built-in catalog is versioned `2026-10-26`. It includes supported OpenAI text models, Gemini 3.8 Flash (including its scheduled January 2027 rate change), Fish Audio, and token-based GPT Image 2.5 and Gemini 3.1 Flash Image rates. Fish `s2.1-pro-free` is priced at zero, separately from paid `s2.1-pro`. Sources: [OpenAI pricing](https://developers.openai.com/api/docs/pricing), [Gemini pricing](https://ai.google.dev/gemini-api/docs/pricing), and [Fish pricing](https://docs.fish.audio/developer-guide/models-pricing/pricing-and-rate-limits). Existing Kimi rates are retained; this audit could not independently retrieve its pricing table. Legacy GPT Image 1 figures are per-image estimates.

New LLM records retain requested effort, reported reasoning/thinking tokens, cache usage, duration, service tier, and request ID when available. Effort is not a price multiplier: its cost is reflected in actual usage. OpenAI reasoning tokens are already included in output tokens; Gemini Interactions thinking tokens are separate and are added to billable output. Image costs require reported token counts and the necessary modality breakdown. Unknown models, incomplete usage, unsupported service tiers, and cache writes without a verified applicable rate remain unavailable. A failed transport request with unknown server outcome is not treated as free. When an API response reports usage but local JSON validation fails, that reported usage is retained.

Historical records preserve their original pricing snapshots and are not repriced. Missing historical effort or token details cannot be reconstructed from the ledger. Published-rate estimates are not provider invoices.

The production estimator makes no provider requests. It excludes reusable stages and uses the story's priced request history matching the current model and effort where available. Historical estimates show a directional range and confidence because output length and retries vary. An optional run budget is a soft guard: it is checked after a chapter completes, so an in-flight request can exceed it.

Use `npm run story:cost -- --story <slug>` for a terminal summary. Add `--from`, `--to`, `--provider`, `--stage`, `--model`, or `--effort` filters and `--format json|csv` for exports of all matching records, across every page. The web studio provides the same ledger under **Costs / Analytics**.
